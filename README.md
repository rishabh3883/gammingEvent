src/
├─ components/      → UI components  
├─ pages/           → Event pages & dashboards  
├─ services/        → API calls  
├─ routes/          → Frontend route config  
├─ models/          → Database schemas  
server.js           → Backend server entry point  


📌 Installation & Setup

    1.Clone the repository
    
      git clone https://github.com/rishabh3883/gammingEvent.git
    
    
    2.Install dependencies
    
      npm install
    
    
    3.Create a .env file with necessary configs (e.g., DB URI)
    
    4.Run the app
    
       npm start
